# Source snapshot

The original `NoC_Router_Fixed(1).zip` is the source snapshot used for this repository import.

The RTL and testbench files are being kept as a reference snapshot before any cleanup or refactoring. The architecture diagrams in `Architecture/Diagrams/` show how the supplied modules fit into the 4×4 mesh clusters and the global inter-cluster layer.

For now, this directory is deliberately not used to hide or rename source files. The next repository pass can place the individual Verilog files into their final RTL and Testbench folders after the structure is reviewed.
